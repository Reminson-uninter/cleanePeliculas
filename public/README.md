## 🚀 Funcionalidades

- **Catálogo responsivo** com grid de produtos.
- **Busca e filtros** para encontrar películas por estilo.
- **Carrinho de compras** com cálculo automático do total.
- **Finalização via WhatsApp** para envio rápido do pedido.
- **Área administrativa** para cadastro e gerenciamento de produtos.
- Integração com **Firebase Firestore** para persistência dos dados.

## 🛠️ Tecnologias Utilizadas

- **HTML5 / CSS3** para estrutura e estilo.
- **JavaScript (ES6+)** para lógica de interação.
- **Firebase Firestore** como banco de dados.
- **WhatsApp API** para envio de pedidos.
